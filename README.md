# Atelier

Bespoke denim workshop in Amsterdam. Live site: [https://olivierwinder.github.io/amsterdam-denim/](https://olivierwinder.github.io/amsterdam-denim/)

## Run locally

```bash
npm install
npx next dev --hostname 0.0.0.0 --port 5173
```

Open [http://localhost:5173](http://localhost:5173). Local URLs stay at `/` (no `/amsterdam-denim` prefix). GitHub Pages is built with `NEXT_PUBLIC_BASE_PATH=/amsterdam-denim`.
